# Сервис по анализу региональной транспортно-логистической системы

## Краткое описание проекта

Сервис должен позволять устанавливать среднее число связей (связь – это пересечение улиц) в топологии транспортно-логистической сети региона для каждого объекта сети со всеми остальными как в регионе в целом, так и по отдельным районам.

## Требования проекта

Разработать веб-ориентированное приложение для исследования и анализа региональной транспортно-логистической системы, позволяющее выявлять самоорганизующиеся региональные пространства и пространства (районы), план (структура) которых задан(-а) регулярным (системным) проектом (self-organization vs top-down planning). Приложение должно позволять загружать и обрабатывать карту любого региона (на примере, Северо-Запада), представлять и визуализировать региональную транспортно-логистическую топологию объектов в виде графа, вычислять параметры данной топологии.
